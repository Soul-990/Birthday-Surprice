BIRTHDAY SURPRISE - HOW TO USE
==============================
1. Unzip this folder anywhere on your computer.
2. Double-click index.html (it opens in Chrome, Edge, Firefox or Safari).
3. Click anywhere to begin.

CUSTOMIZE:
  Open script.js in Notepad (or any text editor) and edit the CONFIG section at the top:
    friendName, senderName, memories (titles + messages), giftTitle, giftMessage,
    letterGreeting, letterBody, letterSignature, fireworksMessage, candleCount.
  Save the file, then refresh the page in the browser.

MUSIC (optional):
  Put your own song in assets/music/ and name it birthday.mp3.
  If it is missing, a soft music-box melody plays instead.

FILES:
  index.html  - the structure of all the scenes
  style.css   - colors, fonts, layout and animations
  script.js   - all behavior: particles, fireworks, sound, typing...
  assets/     - images/, music/, sounds/ (for your own files)
